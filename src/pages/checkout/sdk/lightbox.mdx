# Lightbox SDK

Lightbox SDK es una libreria integral de npm disenada para facilitar la gestion de iframes dentro de tu aplicacion en forma de modales. Te permite crear, manipular y controlar iframes de manera eficiente y efectiva. {{ className: 'lead' }}

Se puede usar facilmente siguiendo unos pocos pasos. Puedes abrir un lightbox simplemente proporcionando la URL de destino, o tambien tienes la opcion de configurarlo con mayor detalle si lo necesitas, ya que ofrece varias funcionalidades para interactuar con el iframe de distintas maneras. Por ejemplo, puedes definir estilos del iframe, ocultar el boton de cierre, cerrarlo directamente y, lo mas interesante, emitir eventos personalizados.

<Note>
Adicionalmente, la pagina que se muestra dentro del lightbox no necesita instalar la libreria. Aprende mas en [Uso sin instalacion](./use-without-install).
</Note>

---

## Instalar Lightbox SDK {{ id: 'installation' }}

Usa tu gestor de paquetes para instalarlo:

<CodeGroup>

```bash {{ title: 'npm' }}
npm install -D @placetopay/lightbox-sdk
```

```bash {{ title: 'yarn' }}
yarn add -D @placetopay/lightbox-sdk
```

</CodeGroup>

## Instrucciones de uso {{ id: 'usage' }}

Para usar Lightbox SDK de forma efectiva, sigue estos pasos sencillos.

### Importar los estilos {{ id: 'import-styles' }}

Es muy importante importar este archivo CSS al usar la libreria. Estos estilos son esenciales para asegurar que el lightbox tenga la apariencia esperada. Sin embargo, si lo prefieres, tambien puedes sobrescribirlos con estilos personalizados despues de la importacion para adaptar la apariencia del lightbox a las necesidades especificas de tu sitio web.

```javascript
import '@placetopay/lightbox-sdk/dist/styles.css';
```

### Uso paso a paso {{ id: 'step-by-step-usage' }}

Importa la libreria `LightboxSdk` e inicializala con tu URL de destino. Luego, usa el metodo `open()` para abrir el Lightbox. Aqui tienes un ejemplo:

```javascript
import { createLightbox } from '@placetopay/lightbox-sdk';

const lightbox = createLightbox('https://your-target-url.com');
lightbox.open();
```

### Uso inline {{ id: 'inline-usage' }}

Alternativamente, si prefieres un enfoque mas breve, puedes inicializar y abrir el lightbox en una sola linea:

<CodeGroup>
```javascript {{ title: 'Con cadena' }}
import { createLightbox } from '@placetopay/lightbox-sdk';

createLightbox('https://your-target-url.com').open();
```

```javascript {{ title: 'Con opcion' }}
import { createLightbox } from '@placetopay/lightbox-sdk';

createLightbox('https://your-target-url.com', { launch: true });
```
</CodeGroup>

<Note>
Asegurate de reemplazar `'https://your-target-url.com'` con tu URL de destino real.
</Note>
