# Contribuir

Usa esta guia para configurar el proyecto Lightbox SDK localmente y contribuir cambios de forma segura. {{ className: 'lead' }}

## Prerrequisitos {{ id: 'prerequisites' }}

Asegurate de tener el siguiente software instalado en tu maquina:

- Git
- Node.js
- npm (generalmente viene con Node.js)

## Instrucciones de instalacion {{ id: 'installation-instructions' }}

1. **Clona el repositorio** Esto descarga una copia del codigo desde GitHub a tu maquina local. Usa el comando `git clone` seguido de la URL del repositorio.

```bash
git clone https://github.com/placetopay-org/lightbox-sdk.git
```

2. **Navega al directorio del repositorio** Una vez clonado el repositorio, navega al directorio recien creado, que deberia llamarse `lightbox-sdk`.

```bash
cd lightbox-sdk
```

3. **Instala las dependencias** Luego, instala las dependencias del proyecto.

<CodeGroup>

```bash {{ title: 'npm' }}
npm install
```

```bash {{ title: 'yarn' }}
yarn install
```

</CodeGroup>

4. **Compila el proyecto** Transpila y empaqueta tu codigo para produccion usando el comando `npm run build`.

<CodeGroup>

```bash {{ title: 'npm' }}
npm run build
```

```bash {{ title: 'yarn' }}
yarn build
```

</CodeGroup>

5. **Crea un enlace simbolico** Luego, crea una version local de desarrollo de tu paquete que pueda usarse en otras ubicaciones de tu maquina.

<CodeGroup>

```bash {{ title: 'npm' }}
npm link ./lib
```

```bash {{ title: 'yarn' }}
yarn link ./lib
```

</CodeGroup>

6. **Inicia el servidor de desarrollo** Ahora estas listo para iniciar el servidor de desarrollo. Este servidor ofrece funciones como recarga en caliente y puede iniciarse.

<CodeGroup>

```bash {{ title: 'npm' }}
npm run dev
```

```bash {{ title: 'yarn' }}
yarn dev
```

</CodeGroup>

## Desplegar docs en GitHub Pages {{ id: 'deploying-docs-to-github-pages' }}

Para desplegar la documentacion de Lightbox SDK en GitHub Pages, hay un script `deploy.sh` que puedes usar. Este script te ayudara a compilar y desplegar la documentacion directamente en el repositorio de GitHub, donde quedara publicada como sitio de GitHub Pages.

Aqui tienes un resumen de como usar el script `deploy.sh`.

<Note type="warning">
Antes de ejecutar el script, asegurate de tener permisos de commit en el repositorio.
</Note>

## Ejecutar el script deploy.sh {{ id: 'run-the-deploy-sh-script' }}

Puedes ejecutar el script de despliegue con el siguiente comando:

```bash
./deploy.sh
```
Otra opcion para ejecutar el script de shell es:

```bash
sh deploy.sh
```

**Si el script no es ejecutable**, puede que necesites agregar permisos de ejecucion al archivo `deploy.sh`:

```bash
chmod +x deploy.sh
```
Ahora deberias poder ejecutarlo.
