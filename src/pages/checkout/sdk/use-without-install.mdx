# Uso de Lightbox SDK sin instalacion {{ id: 'use-without-installation' }}

Si deseas usar la libreria Lightbox SDK sin instalarla, puedes hacerlo gracias a la interfaz de mensajeria que proporciona. Esta funcionalidad se basa en el metodo `postMessage` de la API `window` de JavaScript. En lugar de llamar directamente a las funciones de la libreria, puedes enviar mensajes desde el iframe, que la libreria interpretara.

<Note type="warning">
Este enfoque solo es adecuado para la pagina dentro del iframe del lightbox. Si buscas crear y controlar el lightbox desde tu pagina padre, debes instalar la libreria Lightbox SDK.
</Note>

### Estructura del mensaje {{ id: 'message-structure' }}
La estructura basica de los mensajes que envies debe ser la siguiente:
### type
```typescript
parent.postMessage(
  { type: string; payload?: unknown, preventClose?: boolean }, '*'
)
```
### Detalles
Aqui, `type` es el nombre del evento que quieres disparar, `payload` es cualquier dato adicional que quieras pasar al manejador del evento, y `preventClose` indica si se debe evitar que el lightbox se cierre despues del evento.

### Ejemplo
```javascript
parent.postMessage({ type: 'close' }, '*')
```

## Tipos reservados {{ id: 'reserved-types' }}

La libreria Lightbox SDK usa ciertos tipos de evento para funciones internas. Usar estos tipos disparara las acciones predefinidas asociadas, y tambien ejecutara el callback del mismo nombre (incluyendo la informacion de la interaccion). Los tipos reservados son los siguientes:

| Type | Description |
| --- | --- |
| `close` | Dispara el cierre del lightbox |
| `sendStyles` | Solicita aplicar nuevos estilos al lightbox |
| `hideCloseButton` | Oculta el boton manual de cierre del lightbox |

## Acciones predefinidas {{ id: 'predefined-actions' }}

Dado el uso de ciertos nombres para eventos predefinidos, puedes activar estas acciones enviando un mensaje con el tipo de evento correspondiente. Por ejemplo, para cerrar el lightbox, puedes enviar el siguiente mensaje:

```javascript
parent.postMessage({ type: 'close' }, '*')
```

Esto dara como resultado el cierre del lightbox. Este enfoque puede usarse para interactuar con la libreria Lightbox SDK sin necesidad de instalarla directamente en tu codigo.
