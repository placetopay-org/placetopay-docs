## Notificación {{ id: 'create-notification', tag: 'POST', label: '/api/notifications' }}

Este endpoint permite enviar un mensaje informativo al usuario por los canales que indiques. A diferencia de una [validación](/msv-service/api/validation), una notificación no espera respuesta, no genera `token`, no se puede consultar después y no dispara webhook. El mensaje tampoco incluye enlace de confirmación.
