# Referencia API MSV Service

Bienvenido a la referencia técnica de MSV Service. Nuestra API está construida bajo principios RESTful, utiliza **JSON** para el intercambio de datos y códigos de respuesta HTTP estándar.

## ¿Qué es MSV Service?
Es un servicio que permite enviar mensajes de notificación o validación empleando canales como WhatsApp, SMS o email.

## Entornos y base URL

Todas las solicitudes deben enviarse a las siguientes URL base, dependiendo del entorno en el que te encuentres:

| Entorno | Base URL | Descripción |
| :--- | :--- | :--- |
| **Producción** | `https://msv-service.placetopay.com/` | Entorno transaccional real. |

## Webhook {{ id: 'validation-webhook' }}

Al momento de crear una validación, **msv-service** envía de forma asíncrona un `POST` a la url que configuraste en el campo `webhook_url`. Este payload **NO** es la respuesta síncrona del endpoint `/api/validations` — es una notificación que tu servidor debe recibir y procesar.

### Validación de la firma

Antes de procesar el webhook, recalcula el hash SHA-256 y compáralo con el campo `signature` para validar la autenticidad:

```php
$calculated = hash('sha256', $token . $status . $date . $secret_token);
// Ejemplo: hash('sha256', 'd5d67dcbAPPROVED2022-08-08T17:23:49+00:00ABCD1234')

if ($calculated !== $signature) {
    // Reject — not authentic
    http_response_code(400);
    exit;
}

// Process the webhook
http_response_code(200);
```

Si este valor coincide con el valor proporcionado por el signature, puedes autenticar la respuesta y proceder a persistir el registro en la base de datos.


<Note>
  Bajo ninguna circunstancia expongas tu `secret_token` en ninguna parte accesible a los clientes o usuarios de tu aplicación.
</Note>
