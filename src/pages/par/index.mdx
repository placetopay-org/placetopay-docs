# Placetopay PAR

**PAR** es el portal en el que los tarjetahabientes **inscriben sus tarjetas y gestionan sus pagos recurrentes** (autopagos) con los comercios afiliados a Placetopay. {{ className: 'lead' }}

Desde PAR, una persona vincula una tarjeta, autoriza que un comercio le cobre de forma periódica, consulta el historial de cobros y cancela sus autopagos cuando lo necesite. La tokenización de la tarjeta y la ejecución de los cobros las realiza la plataforma de Placetopay; PAR se encarga de la experiencia del tarjetahabiente y de la configuración de cada autopago.

## Qué resuelve {{ id: 'what-it-solves' }}

Un comercio que cobra de forma recurrente —una suscripción, una cuota, un servicio mensual— necesita que el cliente autorice el cargo una sola vez y que esa autorización quede asociada a una tarjeta. Un emisor que quiere ofrecer pagos recurrentes a sus tarjetahabientes necesita llevarlos a ese mismo punto sin pedirles que vuelvan a escribir los datos de su tarjeta.

PAR expone ese recorrido como una integración: tu sistema solicita un token de acceso, envía al tarjetahabiente a PAR con ese token y PAR lo acompaña hasta dejar el autopago inscrito.

## Quién se integra {{ id: 'who-integrates' }}

PAR reconoce a cada integrador como un **socio** (_partner_) con sus propias credenciales, y ofrece un canal de integración para cada tipo de socio:

- **Comercios** — inscriben un autopago para un servicio concreto de su cliente. Usan una API REST con respuestas JSON, consultan si la inscripción quedó autorizada y pueden mostrar el comprobante del autopago.
- **Emisores** — llevan a sus tarjetahabientes a PAR con las tarjetas que ya conocen, para que inscriban autopagos sin volver a digitarlas. Usan una API con mensajes XML.
- **Integraciones embebidas** — los dos canales anteriores pueden mostrar PAR dentro de un `iframe` en su propio sitio. La sesión embebida explica cómo se entrega la sesión al `iframe`.
- **Administración** — una API interna, autenticada con un token de acceso, mantiene en PAR la configuración de comercios, sitios y socios.

## Cómo funciona, en resumen {{ id: 'overview' }}

1. Tu servidor solicita a PAR un token de acceso de un solo uso, autenticándose con las credenciales de tu socio.
2. PAR valida la solicitud y te devuelve el token junto con la URL a la que debes enviar al tarjetahabiente.
3. Tu sitio envía al tarjetahabiente a esa URL con el token, en una nueva ventana o dentro de un `iframe`.
4. El tarjetahabiente completa la inscripción en PAR: se identifica, elige o vincula su tarjeta y autoriza el autopago.
5. PAR devuelve al tarjetahabiente a la URL que indicaste y, en el caso de los comercios, tu servidor puede confirmar que la inscripción quedó autorizada.

## Requisitos previos {{ id: 'previous-requirements' }}

Para integrarte necesitas:

- **Credenciales de socio**: las emite Placetopay cuando te da de alta como socio de PAR.
- **Un servidor propio**: los tokens de acceso se solicitan desde tu backend, nunca desde el navegador, porque la petición viaja con tus credenciales.
- **Direcciones de retorno**: las URL a las que PAR devolverá al tarjetahabiente al terminar o si ocurre un error. Si vas a embeber PAR en un `iframe`, el origen de tu sitio debe estar autorizado para tu socio.
