## Consultar el estado de la inscripción {{ id: 'check-enrollment-status', tag: 'POST', label: '/restpatpass/v1/services/status' }}

<Row>
  <Col>
    Indica si el tarjetahabiente inició la sesión con el token y completó la inscripción en tu sitio. Consúltalo cada vez que recibas un retorno: volver a tu sitio no significa que la inscripción se completó. Más detalle en [Consultar el estado](/par/merchants/status).

    <ApiReader
      path="/restpatpass/v1/services/status"
      method="post"
      type="header"
      api={props.refs}
    />

    <ApiReader
      path="/restpatpass/v1/services/status"
      method="post"
      api={props.refs}
    />

  </Col>
  <Col sticky>
    <CodeGroup title="Solicitud" tag="POST" label="/restpatpass/v1/services/status">
```bash {{ title: 'Consultar el estado' }}
curl --request POST \
  --url '{URL_BASE}/restpatpass/v1/services/status' \
  --header 'Accept: application/json' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: {TU_LLAVE_SECRETA}' \
  --header 'Commercecode: 1234567890' \
  --data '{"token": "{TOKEN}"}'
```

  </Col>

## Iniciar la sesión del tarjetahabiente {{ id: 'start-cardholder-session', tag: 'POST', label: '/restpatpass/login' }}

<Row>
  <Col>
    La llama el **navegador del tarjetahabiente** con un formulario `POST`, nunca tu servidor. PAR consume el token, abre la sesión y lleva al tarjetahabiente a inscribir el autopago con los datos que enviaste. Se puede enviar en una ventana completa o dentro de un `iframe`, si el origen de tu sitio está autorizado.

    <ApiReader
      path="/restpatpass/login"
      method="post"
      api={props.refs}
    />

    <ApiReader
      path="/restpatpass/login"
      method="post"
      type="response"
      api={props.refs}
    />

  </Col>
  <Col sticky>
    <CodeGroup title="Solicitud" tag="POST" label="/restpatpass/login">
```html {{ title: 'Formulario' }}
<form method="post" action="{URL_BASE}/restpatpass/login">
  <input type="hidden" name="tokenComercio" value="{TOKEN}" />
  <button type="submit">Inscribir autopago</button>
</form>
```
    </CodeGroup>
  </Col>
</Row>
