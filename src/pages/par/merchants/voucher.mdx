# Comprobante del autopago

Cuando una inscripción quedó autorizada, puedes mostrarle al tarjetahabiente el **comprobante** de su autopago, con el detalle de lo que inscribió.

## Mostrar el comprobante {{ id: 'show-voucher' }}

La [consulta de estado](/par/merchants/status) te devuelve el `voucherUrl` cuando la inscripción está autorizada. Envía al tarjetahabiente a esa URL mediante un formulario `POST` desde su navegador, con el token en el campo `tokenComercio`:

```html {{ title: 'Formulario' }}
<form method="post" action="{URL_BASE}/nuevo-ic-rest/tokenVoucherLogin">
  <input type="hidden" name="tokenComercio" value="{TOKEN}" />
  <button type="submit">Ver comprobante</button>
</form>
```

Igual que el inicio de sesión, el comprobante se puede mostrar en una ventana completa o dentro de un `iframe`, si el origen de tu sitio está autorizado para tu comercio.

<Note>
  A diferencia del inicio de sesión, el comprobante se puede abrir más de una vez con el mismo token, mientras la inscripción siga autorizada.
</Note>

Si el token no corresponde a una inscripción autorizada de un comercio, PAR responde `403`.

## Salir del comprobante {{ id: 'final-url' }}

Desde el comprobante, el tarjetahabiente puede volver a tu sitio. PAR envía entonces un formulario `POST` a la `finalUrl` que indicaste al [solicitar la inscripción](/par/merchants/enrollment), con el token en el campo `j_token`:

```text
POST https://www.example.com/par/final
Content-Type: application/x-www-form-urlencoded

j_token={TOKEN}
```
