# Consultar el estado

Después del retorno, tu servidor confirma con el token si la inscripción quedó **autorizada**, es decir, si el tarjetahabiente completó el autopago en tu sitio.

## Consultar {{ id: 'query-status' }}

`POST {URL_BASE}/restpatpass/v1/services/status`

La petición se autentica con los headers `Authorization` y `Commercecode`, como se explica en [Autenticación](/par/merchants/authentication).

<Properties>
  <Property name="token" type="string" isRequired={true}>
    El token que recibiste al [solicitar la inscripción](/par/merchants/enrollment) y que PAR te devolvió en `j_token`.
  </Property>
</Properties>

<CodeGroup title="Solicitud" tag="POST" label="/restpatpass/v1/services/status">

```bash {{ title: 'cURL' }}
curl --request POST \
  --url '{URL_BASE}/restpatpass/v1/services/status' \
  --header 'Accept: application/json' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: {TU_LLAVE_SECRETA}' \
  --header 'Commercecode: 1234567890' \
  --data '{"token": "{TOKEN}"}'
```

```php {{ title: 'PHP' }}
$response = Http::acceptJson()
    ->withHeaders([
        'Authorization' => $secretKey,
        'Commercecode' => '1234567890',
    ])
    ->post("{$urlBase}/restpatpass/v1/services/status", [
        'token' => $token,
    ]);
```

```js {{ title: 'Node' }}
const response = await fetch(`${urlBase}/restpatpass/v1/services/status`, {
  method: 'POST',
  headers: {
    'Accept': 'application/json',
    'Content-Type': 'application/json',
    'Authorization': secretKey,
    'Commercecode': '1234567890',
  },
  body: JSON.stringify({ token }),
});
```

</CodeGroup>

## Respuesta {{ id: 'response' }}

PAR responde `200` tanto si la inscripción quedó autorizada como si no:

<CodeGroup title="Respuesta">

```json {{ title: 'Autorizada' }}
{
  "authorized": true,
  "voucherUrl": "{URL_BASE}/nuevo-ic-rest/tokenVoucherLogin"
}
```

```json {{ title: 'No autorizada' }}
{
  "authorized": false,
  "voucherUrl": null
}
```

</CodeGroup>

<Properties>
  <Property name="authorized" type="boolean">
    `true` si el tarjetahabiente inició la sesión con ese token y completó la inscripción de un autopago en el sitio de tu código de comercio.
  </Property>
  <Property name="voucherUrl" type="string | null">
    URL del [comprobante](/par/merchants/voucher) del autopago. Solo viene cuando `authorized` es `true`.
  </Property>
</Properties>

`authorized` es `false` cuando el token no existe, todavía no se usó para iniciar sesión, fue revocado, pertenece a otro comercio o a otro sitio, o cuando el tarjetahabiente abandonó la inscripción sin completarla. PAR no distingue entre estos casos para no revelar información sobre tokens ajenos.

<Note>
  Consulta el estado cada vez que recibas un retorno, en lugar de suponer el resultado. Una vez autorizada, la inscripción no vuelve a quedar sin autorizar, salvo que Placetopay revoque la sesión.
</Note>

`authorized` confirma que el autopago **se inscribió**, no su estado actual. Si tu sitio exige aprobar los autopagos, puede estar pendiente de aprobación; y el tarjetahabiente puede cancelarlo más adelante desde PAR sin que esta respuesta cambie.
