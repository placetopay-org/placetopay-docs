# Administración de onboarding

El onboarding vincula un comercio con una franquicia de pago para habilitar sus operaciones de tokenización.

La creación de un comercio inicia su onboarding. También es posible solicitarlo con `generate`. El procesamiento con cada franquicia se realiza de manera asincrónica, por lo que la aceptación de la solicitud no garantiza que el onboarding haya finalizado. Consulte `show` o `history` para conocer su estado y, si el consumidor tiene una URL de notificación configurada, consulte también [notificaciones](/token-requestor/integration/notifications/#notificaciones-de-onboarding).

## Generar onboarding {{ id: 'token-requestor-api-admin-onboarding-generate', tag: 'POST', label: '/api/admin/onboarding/generate' }}

Solicita el onboarding para un comercio existente. `franchises` es opcional: si se omite, se procesan todas las franquicias configuradas. Las franquicias soportadas actualmente son `visa` y `master`.

<Row>
  <Col>
    <ApiReader path="/api/admin/onboarding/generate" method="post" api={props.refs} />
  </Col>
  <Col sticky>
    <CodeGroup title="Solicitud" tag="POST" label="/api/admin/onboarding/generate">
      ```bash {{ title: 'Generar onboarding' }}
      curl -X POST https://token-requestor.placetopay.ws/api/admin/onboarding/generate \
        -H 'Content-Type: application/json' \
        -d '{
          "auth": {
            "login": "aabbccdd1234567890aabbccdd123456",
            "tranKey": "ABC123example456trankey+789abc012def3456ABC=",
            "nonce": "MnFrcmZlYjQ0bXk=",
            "seed": "2026-01-15T10:00:00-05:00"
          },
          "merchantId": "f1d0888b-f5a9-445a-8c54-dba63763fbc5",
          "franchises": ["visa", "master"]
        }'
      ```
    </CodeGroup>
  </Col>
