# Onboarding management

Onboarding links a merchant to a payment franchise to enable tokenization operations.

Creating a merchant starts its onboarding. You can also request it with `generate`. Each franchise is processed asynchronously, so accepting the request does not guarantee onboarding has completed. Use `show` or `history` to check its status and, if the consumer has a notification URL configured, see [notifications](/en/token-requestor/integration/notifications/#onboarding-notifications).

## Generate onboarding {{ id: 'token-requestor-api-admin-onboarding-generate', tag: 'POST', label: '/api/admin/onboarding/generate' }}

Requests onboarding for an existing merchant. `franchises` is optional: if omitted, all configured franchises are processed. Currently supported values are `visa` and `master`.
