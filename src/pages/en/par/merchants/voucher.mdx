# Autopay voucher

When an enrollment was authorized, you can show the cardholder the **voucher** of their autopay, with the details of what they enrolled.

## Show the voucher {{ id: 'show-voucher' }}

The [status check](/en/par/merchants/status) returns the `voucherUrl` when the enrollment is authorized. Send the cardholder to that URL through a `POST` form from their browser, with the token in the `tokenComercio` field:

```html {{ title: 'Form' }}
<form method="post" action="{BASE_URL}/nuevo-ic-rest/tokenVoucherLogin">
  <input type="hidden" name="tokenComercio" value="{TOKEN}" />
  <button type="submit">View voucher</button>
</form>
```

Like the login, the voucher can be shown in a full window or inside an `iframe`, if your site's origin is authorized for your merchant.

<Note>
  Unlike the login, the voucher can be opened more than once with the same token, as long as the enrollment remains authorized.
</Note>

If the token does not match an authorized merchant enrollment, PAR answers `403`.

## Leave the voucher {{ id: 'final-url' }}

From the voucher, the cardholder can go back to your site. PAR then submits a `POST` form to the `finalUrl` you provided when [requesting the enrollment](/en/par/merchants/enrollment), with the token in the `j_token` field:

```text
POST https://www.example.com/par/final
Content-Type: application/x-www-form-urlencoded

j_token={TOKEN}
```
