## Request the enrollment token {{ id: 'request-enrollment-token', tag: 'POST', label: '/restpatpass/v1/services/patInscription' }}

<Row>
  <Col>

      type="header"

  </Col>

## Check the enrollment status {{ id: 'check-enrollment-status', tag: 'POST', label: '/restpatpass/v1/services/status' }}

<Row>
  <Col>
    Tells whether the cardholder started the session with the token and completed the enrollment on your site. Check it every time you receive a return: coming back to your site does not mean the enrollment was completed. More details in [Check the status](/en/par/merchants/status).

    <ApiReader
      path="/restpatpass/v1/services/status"
      method="post"
      type="header"
      api={props.refs}
    />

    <ApiReader
      path="/restpatpass/v1/services/status"
      method="post"
      api={props.refs}
    />

  </Col>
  <Col sticky>
    <CodeGroup title="Request" tag="POST" label="/restpatpass/v1/services/status">
```bash {{ title: 'Check the status' }}
curl --request POST \
  --url '{BASE_URL}/restpatpass/v1/services/status' \
  --header 'Accept: application/json' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: {YOUR_SECRET_KEY}' \
  --header 'Commercecode: 1234567890' \
  --data '{"token": "{TOKEN}"}'
```
    </CodeGroup>
  </Col>
</Row>

<Row>
  <Col>
    <ApiReader
      path="/restpatpass/v1/services/status"
      method="post"
      type="response"
      api={props.refs}
    />
  </Col>
  <Col sticky>
    <CodeGroup title="Response">

## Start the cardholder session {{ id: 'start-cardholder-session', tag: 'POST', label: '/restpatpass/login' }}

<Row>
  <Col>
    Called by the **cardholder's browser** with a `POST` form, never by your server. PAR consumes the token, opens the session and takes the cardholder to enroll the autopay with the data you sent. It can be submitted in a full window or inside an `iframe`, if your site's origin is authorized.

    <ApiReader
      path="/restpatpass/login"
      method="post"
      api={props.refs}
    />

    <ApiReader
      path="/restpatpass/login"
      method="post"
      type="response"
      api={props.refs}
    />

  </Col>
  <Col sticky>
    <CodeGroup title="Request" tag="POST" label="/restpatpass/login">
```html {{ title: 'Form' }}
<form method="post" action="{BASE_URL}/restpatpass/login">
  <input type="hidden" name="tokenComercio" value="{TOKEN}" />
  <button type="submit">Enroll autopay</button>
</form>
```
    </CodeGroup>
  </Col>
</Row>

## Show the autopay voucher {{ id: 'show-autopay-voucher', tag: 'POST', label: '/nuevo-ic-rest/tokenVoucherLogin' }}

<Row>
  <Col>
    Called by the **cardholder's browser** with a `POST` form, to the `voucherUrl` of the status check. It shows the autopay voucher and can be opened more than once as long as the enrollment remains authorized. More details in [Autopay voucher](/en/par/merchants/voucher).

    <ApiReader
      path="/nuevo-ic-rest/tokenVoucherLogin"
      method="post"
      api={props.refs}
    />

    <ApiReader

      method="post"
      type="response"
      api={props.refs}
    />

  </Col>
  <Col sticky>
    <CodeGroup title="Request" tag="POST" label="/nuevo-ic-rest/tokenVoucherLogin">
```html {{ title: 'Form' }}
<form method="post" action="{BASE_URL}/nuevo-ic-rest/tokenVoucherLogin">
  <input type="hidden" name="tokenComercio" value="{TOKEN}" />
  <button type="submit">View voucher</button>
</form>
```
    </CodeGroup>
  </Col>
</Row>
