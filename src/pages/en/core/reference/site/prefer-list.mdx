## Create a preferred list {{ id: 'post-core-site-prefer-list-create', tag: 'POST', label: '/core/site/prefer-list/create' }}

<Row>
    <Col>
        This service allows creating a preferred list and associating it with an existing site. If the response is successful, it returns the identifier de la lista.

> ### Nota 
>
> *Para crear correctamente la lista de preferidos it is necessary to enter, along with the required fields, at least one of the siguientes campos: card.Number, ipAddresses o person.document.*

> *En el Person object, the email field is required. The name, surname, company, address and mobile are not necessary when sending the request.*
    
        <ApiReader
            path="/core/site/prefer-list/create"
            method="post"
            api={props.refs}
        />
    </Col>
        <Col sticky>
        <CodeGroup title="Request" tag="POST" label="/core/site/prefer-list/create">
