# MSV Service API Reference

Welcome to the MSV Service technical reference. Our API is built under RESTful principles, uses **JSON** for data exchange, and standard HTTP response codes.

## What is MSV Service?
It is a service that allows you to send notification or validation messages using channels such as WhatsApp, SMS, or email.

## Environments and base URL

All requests must be sent to the following base URL, depending on your environment:

| Environment | Base URL | Description |
| :--- | :--- | :--- |
| **Production** | `https://msv-service.placetopay.com/` | Real transactional environment. |
| **UAT** | `https://msv-service-uat.placetopay.net` | UAT transactional environment. |
| **Develop** | `https://msv-service-dev.placetopay.ws` | Development environment. |

## Webhook {{ id: 'validation-webhook' }}

When a validation is created, MSV Service asynchronously sends a `POST` to the `webhook_url` you configured. This payload **IS NOT** the synchronous response from the `/api/validations` endpoint — it is a notification that your server must receive and process.

### Signature validation

Before processing the webhook, recalculate the SHA-256 hash and compare it with the `signature` field to validate authenticity:

```php
$calculated = hash('sha256', $token . $status . $date . $secret_token);
// Example: hash('sha256', 'd5d67dcbAPPROVED2022-08-08T17:23:49+00:00ABCD1234')

if ($calculated !== $signature) {
    // Reject — not authentic
    http_response_code(400);
    exit;
}

// Process the webhook
http_response_code(200);
```


If this value matches the value provided by the signature, you can authenticate the response and proceed to persist the record in the database.

<Note>
  Under no circumstances expose your `secret_token` in any part accessible to your application's clients or users.
</Note>

## Available services

Explore the available endpoints:
