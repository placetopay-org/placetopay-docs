# MSV Service API Reference

Welcome to the MSV Service technical reference. Our API is built under RESTful principles, uses **JSON** for data exchange, and standard HTTP response codes.

## ¿What is MSV Service?
It is a service that allows you to send notification or validation messages using channels such as WhatsApp, SMS, or email.

## Environments and base URL

All requests must be sent to the following base URL, depending on your environment:

| Environment | Base URL | Description |
| :--- | :--- | :--- |
| **Production** | `http://msv-service.placetopay.com/` | Real transactional environment. |

## Webhook

To use the **Webhook**, you must configure a URL on your server to receive `POST` notifications with the following structure:

```json
    {
        "status": {
            "status": "APPROVED",
            "reason": null,
            "message": "The user has responded",
            "date": "2022-08-08T17:23:49+00:00"
        },
        "token": "d5d67dcb",
        "reference": "0122333444455555",
        "kind": "horus",
        "signature": "c1c0a085837b4042ab6cce604d5a51e665aa038c2eab58a6212037b459612ca1"
    }
```

You can validate that the response comes from PlacetoPay by generating a SHA-256 hash with the following data: `token` + `status.status` + `status.date` + `secret_token`. For this example, if the user secret token is ABCD1234, it would be:

```php
hash('sha256', "d5d67dcbAPPROVED2022-08-08T17:23:49+00:00ABCD1234")
```

If this value matches the `signature` value, you can authenticate the response and proceed to persist the record in your database.

Under no circumstances should you expose your `secret_token` in any location accessible to your customers or application users.
