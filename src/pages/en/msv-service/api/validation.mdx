## Validation {{ id: 'create-validation', tag: 'POST', label: '/api/validations' }}

Create a validation request: **msv-service** sends the user a message through the channels you specify, with a link to approve or reject.

The `201` response confirms that the request was created and at least one channel delivered the message; the status is `PENDING`. If no channel delivered it, the response is `400` and the request is set to `FAILED`. In both cases, `channels` shows the result of each channel (see [Channel results](/en/msv-service/api#channel-results)). The user's response arrives later via [webhook](/en/msv-service/api#validation-webhook), or you can check it with the `token` in [Validation Query](/en/msv-service/api/validation-query).

<Note type="warning">
A `400` response on `/api/validations` means no channel confirmed delivery: the request is set to `FAILED` and no webhook is sent. If any channel returned `delivery_unconfirmed`, the message may still have reached the user, so check with [Validation Query](/en/msv-service/api/validation-query) before taking any action.
</Note>
