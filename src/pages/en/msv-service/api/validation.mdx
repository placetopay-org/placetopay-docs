## Validation {{ id: 'create-validation', tag: 'POST', label: '/api/validations' }}

Create a validation request: **msv-service** sends the user a message through the channels you specify, with a link to approve or reject.

The `201` response only confirms that the request was created and the messages were sent; the status is always `PENDING`. The user's response arrives later via [webhook](/en/msv-service/api#validation-webhook), or you can check it with the `token` in [Validation Query](/en/msv-service/api/validation-query).
