## Notification {{ id: 'create-notification', tag: 'POST', label: '/api/notifications' }}

This endpoint allows you to send an informational message to the user via the channels you specify. Unlike a [validation](/en/msv-service/api/validation), a notification does not await a response, does not generate a `token`, cannot be queried later, and does not trigger a webhook. The message also does not include a confirmation link.

The `200` response confirms that at least one channel delivered the message; if no channel delivered it, the response is `400`. In both cases, `channels` shows the result of each channel (see [Channel results](/en/msv-service/api#channel-results)).
